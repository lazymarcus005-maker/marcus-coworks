# OpenCode Agent Studio — Documentation

A macOS-first, Apple-Silicon-first desktop workspace that wraps
[OpenCode](https://opencode.ai) with a multi-project harness: Goal
Contracts, durable tasks, isolated worktrees, deterministic verification,
an independent verifier, policy gates, budgets, and a human inbox.

OpenCode owns the agent loop, tools, MCP runtime, Skills runtime,
subagents, and provider interaction. Agent Studio owns everything around
it. See [`spec.md`](../spec.md) for the authoritative boundary.
